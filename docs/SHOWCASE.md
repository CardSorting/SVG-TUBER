# 🎨 SVG-TUBER Community Showcase & Ecosystem

Welcome to the SVG-TUBER Community Showcase! This page highlights community-contributed vector avatars, stream layouts, Twitch/YouTube bot integrations, and ecosystem plugins.

## 🌟 Built-in Avatar Gallery

SVG-TUBER ships out-of-the-box with 4 vector avatars:

| Avatar | Style | Layer Features | Preset Physics |
|---|---|---|---|
| **Cyber Neko** | Cyberpunk Anime | Cat ears, hair strands, blush, visor prop support | High ear bounce, spring hair |
| **Chibi Star** | Chibi / Cute | Star eyes, heart eyes, floating halo support | Soft head bounce |
| **Fox Spirit** | Mythical Anime | Kitsune ears, fox tail counter-sway, tear drops | Dynamic wind breeze |
| **Minimal Mascot** | Clean Vector | Minimalist vector geometry, formant visemes | Ultra-lightweight |

## 📸 Community Stream Layouts

### 1. Minimal Stream Overlay Layout
- Avatar embedded via OBS Browser Source (`#obs`) in bottom right corner.
- CRT Scanlines shader enabled at 15% opacity.
- Interactive Boba & Star item thrower enabled for viewer interaction.

### 2. Full VTuber Studio Broadcast Layout
- Desktop Electron mode with transparent window click-through enabled (`Ctrl+Shift+T`).
- Stream Chat Command Bot automatically equipping visors and halo props on viewer subs.

## 🤝 Submitting Your Avatar or Project to the Showcase

Have you created a custom SVG avatar or stream plugin for SVG-TUBER? We'd love to showcase it!

1. Open a Pull Request adding your project or avatar definition to `docs/SHOWCASE.md`.
2. Include a preview image/GIF link and author credits.
3. Submit your PR for community review!
