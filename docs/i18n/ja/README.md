## ✨ 主な機能

- 🎭 **組み込み＆カスタムSVGアバター**: 4種類の高品質ベクターアバター（*Cyber Neko*, *Chibi Star*, *Fox Spirit*, *Minimal Mascot*）を標準搭載。組み込みの**リギングスタジオ**でカスタムSVGの読み込みとタグ付けが可能。
- 👁️ **ハイブリッドAI顔＆カーソルトラッキング**: MediaPipe 478ランドマークFaceLandmarkerによる高速処理。GPU/CPU自動フォールバックとスムーズなマウスカーソル視線追従に対応。
- 🌀 **スプリング物理演算＆アニメ風スクワッシュ＆ストレッチ**: 髪の揺れ、耳の跳ね、体の揺れ、頭部衝撃変形、自動まばたき、自然な呼吸サイクルをシミュレーション。
- 🗣️ **音声フォルマント母音解析**: マイク音声の周波数FFTリアルタイム解析により、口の形状（`A`, `E`, `I`, `O`, `U`, `M`）を自動マッピング。
- ⚡ **Web Audio SFXエンジン**: チャイム音、怒り効果音、効果音などをブラウザ標準Web Audio APIでリアルタイム合成。
- 🎨 **サイバーポスト処理シェーダー**: CRT走査線、VHSノイズ、サイバーブルーム発光、レトロドット絵グリッドフィルター。
- 🕶️ **インタラクティブ小道具オーバーレイ**: サイバーバイザー、ヘッドセット、タピオカティー、天使の輪アバター追従。
- 💖 **インタラクティブアイテム投げ＆粒子エフェクト**: アバターにタピオカや星を投げて頭部物理衝撃と粒子エフェクトを発生。
- 🤖 **配信チャットコマンドシミュレーター**: `!blush`, `!angry`, `!boba` などの視聴者チャットコマンドテスト機能。
- 🎥 **モーションポーズキーフレームレコーダー**: O(1)高速メモリバッファによるモーション録画＆ループ再生。
- 🪟 **OBS Studio＆透過オーバーレイ**: ウィンドウ透過、OBS Browser Source（`#obs`）、グローバルクリック透過ショートカット（`Ctrl+Shift+T`）。
- 🚀 **ゼロメモリリーク＆サイクル最適化**: 解離型rAFループ、WeakMap DOMエレメントキャッシュ、事前割り当てオブジェクトプールを搭載。

## 🚀 クイックスタート

### 前提条件
- [Node.js](https://nodejs.org/) (v18.0 以上推奨)
- [npm](https://www.npmjs.com/)

### インストール

```bash
# リポジトリのクローン
git clone https://github.com/cardsorting/SVG-TUBER.git
cd SVG-TUBER

# 依存関係のインストール
npm install
```

### 開発サーバーの起動 (Webモード)

```bash
npm run dev
```
ブラウザで `http://localhost:5173` を開きます。

### デスクトップアプリの起動 (Electronモード)

```bash
npm run electron:dev
```

---

## 🎥 OBS Studio 連携方法

1. OBS Studioで **ブラウザソース** を追加します。
2. URLに `http://localhost:5173/#obs` を設定します（`#obs` ハッシュにより背景が自動透過されます）。
3. 幅 `1920`、高さ `1080` に設定します。
